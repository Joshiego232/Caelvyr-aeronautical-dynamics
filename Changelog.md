# Caelvyr Aeronautical Dynamics — Changelog

## Release V1.1.0
**Premium Flight Deck, Industrial Hangar & Scenery Upgrade**

- Replaced the previous Skybound-era selector styling with a complete graphite-and-champagne aviation-console presentation across aircraft, airport, start-position and conditions selection, including mobile/tablet layouts.
- Replaced the basic hangar presentation with an industrial aircraft-service hangar featuring steel portal frames, roof structure, work-bay lighting, safety markings and Caelvyr signage.
- Made the hangar preview camera stationary; mouse or touch dragging is used to pan and tilt instead of automatic camera rotation.
- Added an offline-safe procedural satellite-style terrain material with varied land-cover patches, field boundaries, rural paths and river-like details. This is generated locally; it does not claim to be live satellite photography.
- Added a SATELLITE ON/OFF overlay to the airport selection map.
- Added an Ultra-only terrain shader enhancement for fine tonal/slope detail, while keeping lower graphics presets available for less powerful devices.
- Removed the tree-cluster seeding and cluster-count panel. Trees are distributed individually according to biome and terrain rules; the enlarged instanced-tree pools and mobile-friendly instancing approach remain.
- Restored the Conditions tab to its intended purpose rather than displaying forest statistics.
- Preserved the existing Android app, world airport map, hangar preview placement, mobile MAP control fix, pause-to-title option, and other V1.0.1 improvements.

## Release V1.0.1
**Hangar, navigation, selector and forest improvements**

- Moved the aircraft-selection hangar to a separate preview area away from the active runway and gate spawn.
- Reworked aircraft, airport, start-position and settings panels with a more modern aviation-console interface and mobile-friendly layout.
- Added a selectable world airport map with tap/click airport markers, zoom controls and a fit-world action.
- Fixed the mobile MAP control to use the map's actual visibility state, and kept the flight map control available during flight.
- Added a RETURN TO TITLE SCREEN action to the pause menu.
- Increased instanced-tree capacity while avoiding per-tree shadow casting to reduce rendering cost. The clustered-tree experiment is removed in V1.1.0.

## Release V1.0.0
**Initial Android release**

- Introduced the redesigned launch and title screens.
- Added the Play, Settings, and Plugins, Add-ons & Patches menus.
- Added aircraft selection and aircraft previews in the hangar.
- Added world and airport selection before starting a flight.
- Added graphics, flight assistance, and control configuration options.
- Introduced the in-app Check for Updates feature.
- Added release version information and changelog access.
